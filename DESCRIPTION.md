# Repository Description

Easy Work India is a web-based work management portal prototype built with HTML, CSS, vanilla JavaScript, Node.js, and SQLite. It includes a responsive public website, user account interfaces, an admin dashboard, and backend data management for users, projects, rates, tasks, and work logs.
